# 风驱动原教旨：只靠风走路

> 状态：方向文档（2026-10-11）。这是产品的主打约束，不是已完成的功能。现有风驱动能力见 [SIM-DESIGN.md](SIM-DESIGN.md) 与 EXPERIMENTS §14；检验方式见 [VALIDATION.md](VALIDATION.md)；任务卡见 [ACTIONS.md](ACTIONS.md) 的 W 与 V 两节。

## 1. 约束

> **产品结论里的走兽，能量只来自风（以及它充进气动储能的风能），可以再加重力（坡）。不用电，不用预先上紧的弹簧。**

为什么：Jansen 的走兽就是这样（风、帆、瓶子、泵、气动肌肉）。这个约束也让项目有一个别人没有系统回答过的问题：

> 一只只靠风的走兽，起步最少要多大的风？低于多大的尺寸它走不动？

## 2. 两个层次，不能混

| 层次 | 能量来源 | 用途 |
|---|---|---|
| **风驱动**（产品结论） | `wind`（含风充能的气压储能），可加 `gravity`（斜坡） | 排行榜、优化目标、报告里的结论 |
| **测试台**（仪器） | `test_rig`：电机伺服以恒定慢速转曲柄 | 测机构的负载扭矩曲线 T(θ)，帆必须克服的就是它；做仿真核对；虚拟测力计 |

规则：
- 测试台设计**不进入**排行榜和优化目标，界面上标明"测试台"。
- 电机驱动的结果可以用来**解释**风驱动（例如"这条 T(θ) 的峰值决定起步风速"），但不能被当成走兽的性能。
- 能量来源**不是新输入字段**：它由驱动类型决定（`sail` → wind，`motor` → test_rig），由注册表声明，在运行结果里以指标 `wind_only` 输出。理由：单独做一个字段会和 `drive.kind` 重复，两者可能互相矛盾；而 AGENTS.md 的规则是"不要往 schema 里偷偷加参数"，派生量不需要进 schema。将来出现混合驱动（风加储能）时，由驱动自己声明。

## 3. 尺度论证（待仿真检验的假设）

整体等比例放大 L 倍：
- 风对帆的力正比于面积，∝ L²；
- 重量 ∝ L³（实心体）；销轴摩擦∝法向力，也随重量增长。

所以大机体对风更有利。真实机体是薄壁管，重量增长介于 L 与 L³ 之间，具体指数要靠仿真。这解释了两件事：Jansen 的走兽都很大；小的打印件配风扇只能勉强动。**这是假设，没有被检验过**，检验方法是 W-05 的旗舰实验（起步风速随放大因子的曲线）。结论完全可能是"低于某个尺寸走不动"，这就是结果，不是失败。

## 4. 需要的模型

| 模块 | 内容 | 现状 | 已知风险 |
|---|---|---|---|
| 风场 | 定常、阵风、湍流谱、随高度的风廓线、风与机体朝向的夹角 | 有定常和阵风 | 湍流谱的选择会改变阵风结论，需标 `assumption` |
| 驱动元件 | 阻力帆、竖轴转子、拍动翼、机体与管子阻力 | 只有阻力帆；风只作用于帆（S2 已做，S5 机体阻力未做） | 低雷诺数下阻力系数不确定；各转子功率系数 Cp 的数值未核实，使用时标 `[unverified]`。理论上限 Betz 极限 0.593 是标准结论 |
| 传动 | 帆到曲柄的传动比 | 场景参数 `sail_gear` | 应成为可优化的基因 |
| 摩擦与阻尼 | 曲柄处的库仑摩擦和粘性阻尼；**连杆销轴的摩擦** | 曲柄处与连杆销轴都有命名参数（销轴：`walker.joint_friction`、`walker.joint_damping`，默认 0 表示理想，W-02） | EXPERIMENTS §14：帆驱动下 82% 的输入功进了这两个假设值，所以起步结论大半取决于猜测 |
| 静摩擦 | 低速时的真正库仑静摩擦 | MuJoCo 用软化摩擦 | **起步阈值正好落在软化摩擦最失真的低速粘滑区**，所以需要独立求解器 K2（V-02） |
| 储能 | 气瓶、活塞泵、阀、气动肌肉：理想气体加孔口流量 | 无 | 常数需要实测或文献，先标 `assumption` |

## 5. 指标

- **起步风速**：从静止开始，曲柄转满一整圈所需的最小定常风速，二分法求，带不确定区间。
- **风到行进速度比**、**运输成本**（无量纲）。
- **最小可行尺寸**：给定设计族，起步风速低于某个现实上限（例如 15 km/h，仅作 V3 的数量级检查）的最小放大因子。
- **阵风稳健性**：在阵风序列下的前进距离的最坏 10% 均值（CVaR）。
- **一天期望距离**：用公开气象数据的风速分布换算。永远标成"模型输出，不是预言"。

## 6. 诚实规则（风驱动专用）

1. 任何起步风速必须同时给出对假设参数的敏感性区间（W-03），不允许只给一个数。
2. 摩擦、阻力系数这类假设值，默认值改动必须同步更新敏感性表。
3. "不走"也是结果，必须记录（EXPERIMENTS 里写数字）。
4. Jansen 的"约 15 km/h"是艺术家的陈述，不是测量，且对应的机体尺寸和重量未知；只能作为数量级检查。
5. 本文件里没有出处的数字都是待核实的。
