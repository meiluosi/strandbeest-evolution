# ADR-0006: 遥测与几何的数据格式

**状态：提议（等待拍板）** · 单向门 #7

**背景** 运行的数组存成 npz（无模式、不可流式、读取要整个文件），回放帧用 JSON 经 API 传。接触力、能量项、事件加进来，数据量会翻倍；实时流式和跨语言读写也需要模式。

**选项**
1. 保持 npz + JSON。
2. 遥测用 **Arrow/Parquet**（列式、带模式、可流式追加、按列读）；几何与场景用 **glTF**；小元数据用 JSON；npz 做旧格式导入器。
3. HDF5/Zarr：适合大数组，但生态和流式不如 Arrow 贴合我们的需求。

**推荐** 方案 2。glTF 还有个额外的好处：**回放可以存成 glTF 动画**，用任何通用查看器打开，利于分享和复现包。

**后果** 仿真输出层和 API 的回放端点要改；播放器按"层"请求列（足迹、力、能量）；旧运行通过导入器读取，不丢。

**验证** 同一运行的 npz 与 Parquet 数值逐列一致；按列读取的耗时与体积基准；glTF 动画在第三方查看器里能播放。
