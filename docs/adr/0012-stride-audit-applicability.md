# ADR-0012：步幅审计的参考模型与适用条件

状态：**接受**（2026-11-04，用户明确选择“采用 ADR-0012 修订方案”）。本决定授权实施版本化审计；不改变默认物理参数，也不表示 H2-01 已验收。

## 背景与已核实证据

[H2-01](../ACTIONS.md) 要求“固定原始 64 样本及原审计门槛零失败；不得删样本、改门槛或忽略异常”。当前 `nominal_stride_m` 使用单足轨迹的非负行程除以占空比；它不包含旋转方向、多足支撑次序或球形足的转动。因而它不能普遍解释为实际多足机构的无滑移步幅。

EXPERIMENTS §54/§64/§70 已分别检查解析轨迹、独立 Python 计算、共享 Rust 双端计算以及动态步长细化。以下数字都来自已经保留的原始样本，没有另挑几何参数：

第20号的独立理想预测和动态结果同为反向；强迫其符合正向旧目标没有物理依据。第61号则说明**仅替换参考也不足以通过**：动态结果仍偏离理想球足预测约38.3%。有向理想参考假定刚性、无滑移、无腾空、躯干不转动；它不是包含柔顺、多点接触与惯性的动力学定律。把不符合这些假设的运行直接排除，也不能证明仿真可靠。

具体输入、全部32组动态细化和未通过结果见 `experiments/hardening-g1-rigid-convergence-2026-11-04.json`；原全64样本三组结果仍为10/3/3失败。

## 选项

1. **保持现有验收定义。** 原公式、样本和阈值完全不动；H2-01 继续未验收。不能通过为第20号制造正向运动来满足该公式，也不能将旧失败重命名为通过。
2. **按物理适用条件修订审计（推荐）。** 保留原64样本、全部旧结果和15%几何比较阈值；另立版本化的新审计，修正参考公式和适用条件。新旧结果始终并列，接受新定义不等于接受当前实现。

## 推荐方案的具体验收约束

- 原64个输入、seed=1以及能量2%、闭环5 mm、穿透5 mm、支撑检查保留；不删除停转、反向、近零步幅或难例。缺失/非有限证据仍为未验证。
- 有向几何参考只在预先声明且被检查的刚性、无滑移、无腾空、姿态约束条件下使用；保持15%阈值。近零或互不相容的支撑不能靠扩大分母、取绝对值、忽略符号取得通过。
- 不适用几何参考的样本必须给出独立动力学对照或可追溯实测；仅解释为“有滑移/有柔顺”不算通过。接触运动的代数分解是定位证据，不作为独立验证。
- 每个差异必须区分公式错误、实现错误、物理模型差异与未解决；未解决或缺少独立对照的样本继续阻止整体验收。新定义不得把“不适用”变成绿色通过。
- 任何运行语义变动都更新实现身份/缓存、原生与浏览器契约、相关用户提示和回归；默认物理参数调整仍需原全64样本、金标、跨端与慢测试，不从诊断网格选择一个有利参数便推广。
- 重新提交逐样本、逐检查的新旧对照后，才可决定 H2-01 是否满足修订后的要求。当前有向参考、第61号动态差异和公开曲柄实测失败均不因本决定得到验收。

## 决策边界

该选择影响“零失败”的含义，因此已先请求并取得用户明确选择。新审计按本记录实施，旧审计作为版本1保留并列记录。`nominal_stride_m` 仍明确命名为历史启发式，不能作为新审计的通用物理参考。H3中不依赖此结论的组件工作可以继续，但不宣称其 H2 依赖已经满足。

English: the user accepted this correction to an invalid universal stride reference on 2026-11-04. Preserve the original corpus, thresholds and historical failures. The new audit must explicitly verify reference applicability and require independent evidence for every remaining discrepancy; inapplicability is not a pass. Implementation and H2 acceptance remain separate.

## 逐步观测的实施核对（2026-11-04，EXPERIMENTS §77）
