# ADR-0001: 资产身份与引用

**状态：提议（等待拍板）** · 单向门 #1

**背景** 现在设计、运行、测量互相引用都靠名字（`design_name`）。改名、复制设计、两个人同名设计，引用就会悄悄指错。后面还要有谱系、版本、缓存，全都需要"这个东西到底是哪个"。

**选项**
1. 继续用名字（现状）：简单，但改名即破坏引用，无法做谱系。
2. 稳定 ID（ULID 或 UUIDv7）+ 名字只做显示：改名安全；ULID 按时间可排序。
3. 纯内容哈希：不可变产物很合适（运行、导出），但设计会被不断编辑，哈希一直变，不适合当身份。

**推荐** 方案 2 为身份；对**不可变产物**（运行、导出包、测量）额外记录内容哈希用于缓存和防篡改。引用写成 `{id, 可选 version|hash}`。

**后果与迁移** 所有 schema 加 `id`；`design_name` 等改为 `design_id`（保留旧字段做一次性迁移，写迁移函数和往返测试）；API 路径改用 id，名字做查询。一次性迁移，之后稳定。**越晚迁移，要迁的数据越多。**

**验证** 重命名设计后，所有引用它的运行和测量仍能解析；复制设计产生新 id 并在谱系里记父。
