# 检验与证据：每个数字凭什么可信

> 状态：方向文档（2026-10-11）。接受 **E3（自己的实测）暂时为空**。任务卡见 [ACTIONS.md](ACTIONS.md) 的 V 节。

## 1. 先分清两个词

- **核对（verification）**：代码是否正确实现了我们写下的模型。可以和别的求解器、文献里的方程对比。
- **验证（validation）**：模型是否符合真实世界。需要实测。

我们现有的大部分检验（能量账闭合、镜像对称、与简化模型对照）是核对。验证几乎为零。文档里不允许把核对说成验证。

## 2. 证据等级

每个结果（指标、排名、曲线）带一个等级，界面与报告默认显示：

| 等级 | 含义 | 例子 |
|---|---|---|
| **E0** | 只有一个模型算过 | 现在大多数结果 |
| **E1** | 至少两个**独立**求解器在约定容差内一致 | 运动学足端轨迹：TS 与 Python 与 MuJoCo；K2 与 MuJoCo 的步幅 |
| **E2** | 与**公开数据或文献**在不确定度内相符 | 足端轨迹与已发表的实验轨迹对比 |
| **E3** | 被**可追溯的实测**验证（自己或社区） | 暂无 |

规则：
- 等级跟着**结果**走，不跟着代码走。同一个求解器，步幅可以是 E1，扭矩仍是 E0。
- 等级只会因为新证据升高；任何已知 bug 或旧结果被更正，相关结果降级并留痕。
- 优化器和智能体基准**不信 E0 的排名**：需要先通过排名稳定性检查（V-04）。

## 3. 检验梯子（用能拿到的数据）

公开数据比预想的少（2026-10-11 的粗检索，不是系统综述）：

| 量 | 能找到的 | 级别上限 | 说明 |
|---|---|---|---|

| 起步风速 | 没找到论文级测量；Jansen 官网陈述（Aurum 期约 15 km/h） | 数量级检查 | 艺术家陈述，体型未知 |

## 4. K2 独立求解器的约束

- 范围：平面、刚体、单自由度机构驱动，库仑摩擦（静摩擦与动摩擦），脚与地面单边接触，风驱动。
- **独立**：不 import MuJoCo，不共享其约束或接触代码。输入同一份 `LinkageSpec` 与 Scenario，输出同一份 Run 的一部分。
- 实现语言：先 TypeScript（`packages/core` 旁，能在浏览器里跑，也服务交互演示），再按需要有 Python 对照。
- 方法选择在 V-02 的设计阶段决定并写入 ADR；候选：互补性约束（LCP）的冲量法，或带摩擦的约束力方程的事件驱动解法。选定前不写代码。
- 验收见 V-02。
