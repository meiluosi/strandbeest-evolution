# 检验与证据：每个数字凭什么可信

> 状态：证据规则与当前边界（2026-11-04 核对，保留 2026-10-11 的方向）。**本项目尚无验收通过的 E3 结果**；已取得32份公开曲柄记录，16份独立留出检验仍有工况失败（EXPERIMENTS §71），不能据此升级走兽模型结果。当前加固任务见 [ACTIONS.md](ACTIONS.md) H 节，来源审查见 [RESEARCH-NOTES.md](RESEARCH-NOTES.md)。

## 1. 先分清两个词

- **核对（verification）**：代码是否正确实现了我们写下的模型。可以和别的求解器、文献里的方程对比。
- **验证（validation）**：模型是否符合真实世界。需要实测。

我们现有的大部分检验（能量账闭合、镜像对称、与简化模型对照）是核对。验证几乎为零。文档里不允许把核对说成验证。

按用户接受的 [ADR-0012](adr/0012-stride-audit-applicability.md)，`Run.audit` v2分别记录 `passed`、`failed`、`unverified`，同时保留完整v1结果。通过只涵盖声明的数值检查及已核对适用条件的有向几何参考，`physical_validation_implied` 始终为false。未满足刚性、无滑移、连续支撑或固定姿态条件的运行，需要独立动力学/实测证据；当前尚无接入此证据的适配器，因此保持未验证。缺少原始轨迹、只有几何公式可计算、Python/WASM结果一致，都不能替代这项验证。原64样本全部无失败且无未验证才满足H2-01；§72重审现有192条记录无一通过。

## 2. 证据等级

每个结果（指标、排名、曲线）带一个等级，界面与报告默认显示：

| 等级 | 含义 | 例子 |
|---|---|---|
| **E0** | 只有一个模型算过 | 现在大多数结果 |
| **E1** | 至少两个**独立**求解器在约定容差内一致 | 指定场景下 K2 与 MuJoCo 的步幅对照；共享 Rust 的两个语言绑定不算独立求解器 |
| **E2** | 与**公开数据或文献**在不确定度内相符 | 足端轨迹与已发表的实验轨迹对比 |
| **E3** | 被**可追溯的实测**验证（自己或社区） | 暂无 |

规则：
- 等级跟着**结果**走，不跟着代码走。同一个求解器，步幅可以是 E1，扭矩仍是 E0。
- 等级只会因为新证据升高；任何已知 bug 或旧结果被更正，相关结果降级并留痕。
- 优化器和智能体基准**不信 E0 的排名**：需要先通过排名稳定性检查（V-04）。
- Python/WASM 的共同内核测试属于实现一致性核对；MuJoCo 原生/WASM 也不是两个独立物理模型。历史 E1 结果只适用于原设计、工况、输出量及容差，不自动继承给新版本或新设计。

> 2026-11-03 状态更正：V-01 的旧 E2 升级已撤回，原因是数字化来源链不可复核（EXPERIMENTS §46）。下表是可达到的级别上限，不能当作当前已获得的证据。

## 3. 检验梯子（用能拿到的数据）

以下是截至 2026-11-04 已核对的候选范围，不是系统综述，也不表示已完成本项目的对照：

| 量 | 能找到的 | 级别上限 | 说明 |
|---|---|---|---|
| 足端轨迹 | Pop 2014 的实物/CCD 方法已核实，原24点来源未核实；Nansai 2015 有原型几何比较 | E2（仅运动学） | 旧E2已撤回；尚未用可追溯原始轨迹复核我们的模型 |
| 动力学模型 | Nansai 等 2015 *Journal of Robotics*：四足 Jansen 单驱动动力学模型 | E1（独立实现对比） | 它自己的验证是仿真，不是实测 |
| 扭矩、电流 | DaRUS 四连杆原始运动/电流；Ingram 走兽电功率实验 | 待逐量审查 | 前者缺绝对机械/扭矩标定链；后者详细数据指向未取得的光盘，电功率不是已标定输出扭矩；均未完成本项目的留出验证 |
| 起步风速 | Jansen 官网陈述及社区风扇实验 | 数量级线索 | 仍缺仪器标定、误差与可留出的起步原始数据 |

| 台阶 | 做什么 | 上限 | 任务卡 |
|---|---|---|---|
| **V0 几何** | Jansen 的 13 个数字，足端轨迹与已发表轨迹对比 | E2（运动学） | V-01 |
| **V1 独立求解器** | K2：独立的平面刚体求解器，真正的库仑静摩擦，与 MuJoCo 对照步幅、起步 | E1 | V-02 |
| **V1b 文献模型** | 复现 Nansai 2015 的模型与结果 | E1 | V-03 |
| **V2 排名稳定性** | 换摩擦模型、刚度、时间步、求解器，设计排名是否稳定 | 决定哪些结论能信 | V-04 |
| **V3 公开视频** | 从公开视频数每圈步幅和速度（`packages/rig` 视频追踪可复用） | 数量级 | V-05 |
| **V4 社区数据** | 公开"如何测一只走兽"和 Measurement 提交格式，征集数据 | E3 | V-06 |

K2 的存在理由：风驱动的起步阈值落在低速粘滑区，MuJoCo 的软化摩擦在这里最不可信（见 WIND.md §4）。两个**独立实现**一致，比反复调同一个引擎的参数更有说服力。

## 4. K2 独立求解器的约束

- 范围：平面、刚体、单自由度机构驱动，库仑摩擦（静摩擦与动摩擦），脚与地面单边接触，风驱动。
- **独立范围**：K2动力学/接触算法不调用MuJoCo，也不共享其约束求解代码；使用同一份`LinkageSpec`、Scenario、Rust几何及模型生成器。后端工厂目前仍导入MuJoCo适配器，因此不承诺软件包可脱离该依赖安装运行。独立惯性核对使用原生MuJoCo作为对照，不属于K2运行算法。
- 当前实现是 Python `packages/sim/src/strandbeest_sim/backends/k2_backend.py`；浏览器物理路径使用 MuJoCo WASM。原先“先 TypeScript”的方向已被实际实现取代。
- EXPERIMENTS §73修复K2执行时间步、球足转动和周期插值；4,096相位核对只证明接触运动实现的一致性。§74修复离散功/冲量账，原64样本全量复跑无能量/闭环/穿透失败，最大能量残差0.458%；v2仍为64未验证，不能据此接受ADR-0012所需的独立对照。`e_numerical`只报告积分能量误差，禁止抵消审计残差；法向/切向接触转移保留符号，闭合账目也不验证接触稳定化或完整惯性模型。
- §75已补齐四维降阶状态的逐杆构型相关惯量、完整运动耦合和重力。原4,096次独立惯性组装核对及扩充后的6,144次接触运动核对通过；1440点插值的六处初始失败保留，细化到2880点且未放宽门槛。这些检查共享几何，不代替整机独立动力学验证。独立静/动摩擦参数、零速销轴锁定和接触稳定化仍有缺口，见 [ADR-0010](adr/0010-k2-independent-solver.md) 的实施核对。
- §75最终原64样本复跑最大能量残差0.769%，闭环/穿透检查无失败；v2仍为0通过、0失败、64未验证。第61号与有向理想步幅差异33.36%，适用条件尚未核实，因此只是诊断差异，不能将其改写为通过或已获得独立物理证据。
- §76原64样本完整审计为0通过、1失败、63未验证；第16号支撑率5.58%的失败保留。仅改为每步记录便得到3.10%，21列原始数据在原采样点逐位一致，证明日志采样可改变判定。峰值闭环/穿透也仅从日志样本统计，须补齐逐步证据，不能把稀疏样本未超限当成全过程无超限。
- §76独立模式枚举与64个最终冻结状态一致，16个旧状态复放通过；仅证明单步接触方程一致。第61号在0.025 ms下未完成30 s诊断，即使接触残差和能量账合格也不建立时间收敛。独立动态/实测验证仍缺，H2-01不验收。
- §77新增可选 `Run.audit_observation`，逐步累计支撑、闭环和穿透峰值并核对计数、时间、Scenario及原始样本；API保存/回放、Agent重审和浏览器累计使用同一契约。旧记录缺失覆盖仍未验证，旧采样支撑结果留在legacy。两个K2样本三种记录频率及十组原生逐步对照验证统计一致，未修改阈值。几何参考的原始轨迹条件、能量/步态窗口及独立动力学证据仍另行检查；40次新运行不构成全64验收。
- 历史验收见 V-02；本轮稳定性与证据门槛见 H2。K2 的独立接触实现不等于其所有物理假设均已验证。

## 5. 对外承诺

发布材料里只允许写：
- "E1：两个独立求解器一致"、"E2：与某文献在某范围内相符"，附出处；
- 不允许写"经验证"，除非是 E3。
