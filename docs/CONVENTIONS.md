# 坐标系、符号与单位约定

> 这份文档是**契约**：代码和测试以它为准。改它等于改接口，需要同步改测试（`packages/core/src/conventions.test.ts`、`packages/common/tests/test_conventions.py`、`packages/sim/tests/test_conventions.py`）。来源：ADR-0002。

## 1. 单位
- 引擎边界一律 **SI**：米、千克、秒、弧度、牛顿、牛·米。字段名带单位后缀（`_m`、`_mm`、`_kg`、`_rad_s`、`_nm`）。
- **连杆长度**用无量纲的"长度单位"，每个设计用显式字段 `walker.unit_m`（米/单位）换成米。长度单位**不是**毫米也不是米，是设计的内部尺度。
- 接触刚度 `solver.contact_stiffness` 的单位是 **1/s²**（MuJoCo 的参考加速度刚度，按有效质量归一化），**不是 N/m**。物理足垫刚度约等于它乘以脚处的有效质量；二者不能直接比较。
- 时间：**仿真时间**（秒，从开始驱动算起，不含 settle 阶段）与**墙钟时间**分开命名；不要混用。

## 2. 坐标系
| 名称 | 轴 | 用在哪 |
|---|---|---|
| **髋关节系（2D）** | x 前进、y 向上，原点在髋关节铰点 G | 连杆求解（TS 与 Python）、步态指标、制造规划、设计器画布 |
| **世界系（MuJoCo）** | 右手；x 前进、y 横向、z 向上 | 仿真、回放帧、`scene.json` |
| **three.js 系** | 右手；x 前进、y 向上、z 朝向观察者（= 世界系的 −y） | 3D 视图 |

映射（唯一一处实现：`packages/core/src/frames.ts`）：
- 髋关节系 (x, y) → 世界系 (x, ·, z=髋高 + y)；
- 世界系 (x, y, z) → three.js (x, z, −y)（绕 x 轴转 −90°，是旋转，不是镜像）；
- 斜坡：仿真里用**倾斜的重力**表示，显示时把整个场景绕 three.js 的 z 轴转 `+slope`（+x 是上坡方向）。

## 3. 曲柄角：三个角，一组关系
| 符号 | 含义 | 正方向 |
|---|---|---|
| **ψ** | 曲柄沿**行走方向**转过的角 | 沿行走方向转为正（电机、风帆驱动使 ψ 增加，机体前进） |
| **θ** | 连杆求解用的角，髋关节系里**逆时针**（x 到 y）为正 | 逆时针 |
| **q** | MuJoCo 里曲柄铰链的角（轴 +y） | 在 (x 向右, z 向上) 的视图里**顺时针**为正 |

关系：`θ = direction × ψ`，`q = −θ`，其中 `direction ∈ {−1, +1}`：**Jansen 腿是 −1**（ψ 增加时 θ 减小，脚在着地段相对髋关节向后运动，机体向前）。多腿时第 i 条腿的初始相位是 `θ_i = θ + 2π·i/n`。

## 4. 方向的判据（测试固定的就是这几条）
1. 曲柄端点 `C = (a, l) + m·(cos θ, sin θ)`：θ 逆时针为正。
2. `direction = −1` 的 Jansen 腿：ψ 增加时，**着地段**的脚相对髋关节**向后**（x 减小）。
3. MuJoCo 构建器：初始时曲柄端点在世界系的位置等于 `(C.x·unit, ·, 髋高 + C.y·unit)`；曲柄铰链参考角 = `−θ_i`。
4. 仿真：`direction = −1` 且电机让 ψ 增加 → 躯干沿 +x 前进；把 `direction` 翻成 +1，同一驱动使躯干**后退**（这条同时检验测试对符号翻转是敏感的）。
5. three.js 映射：世界系的前进方向 +x 仍是 +x，向上 +z 变成 +y。

## 5. 命名与引用
- 资产有稳定 ID（ADR-0001）；名字只用于显示。
- 角度一律弧度；界面显示度数时在显示层转换，不进入数据。
